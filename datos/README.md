# Datos

- `sinteticos/`: CSV generados por `matlab/utils/generar*.m`, siempre con
  `rng(42)` y rotulados «sintético» en texto, script y figura (§5.8, §9.1).
- `reales/`: solo si la licencia de la fuente lo permite. Si no, este
  directorio contiene únicamente un `README.md` con la URL y las
  instrucciones de descarga (nunca el archivo con derechos de terceros).

_Sin datasets todavía — ninguno de los 18 capítulos tiene contenido más allá
del capítulo de prueba de Fase 0, que no usa datasets externos (la curva de
Bass se genera analíticamente en el propio script)._
